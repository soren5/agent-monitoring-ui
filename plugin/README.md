# Agent Monitoring UI — Obsidian Plugin

This directory holds the Obsidian desktop plugin that monitors NanoClaw agents.

Milestone 1 scope:
- live agent dashboard (connect to one NanoClaw instance)
- inspect an agent's activity / reasoning / output
- send a message to an agent and observe delivery and response

Milestone 1 scaffold task: M1-T04 / M1-T05 on branch `feature/m1-ui-scaffold`.

Canonical specification lives in the Requirements agent workspace
(`groups/requirements/agent-monitoring-ui-srs-draft.md` and
`groups/requirements/milestone-1-implementation-plan.md`).
